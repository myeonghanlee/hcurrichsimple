## 3. 파이썬 검증 코드 업데이트 (`verify_curriculum_v6.py`)

사용자의 정밀 검증 요구사항을 반영하여 다음과 같은 고도화된 로직을 적용했습니다.

1.  **선택 블록 전파 로직 (Elective Block Propagation)**:
    *   `n학년 선택`으로 묶인 과목군을 하나의 블록으로 인식합니다.
    *   해당 블록의 특정 학기에 `xx(택n)`이 명시되어 있다면, 해당 블록 내의 **모든 과목**을 해당 학기에 선택 가능한 최대 범위로 간주하여 학점을 합산합니다.
2.  **다양한 교과군 명칭 대응**:
    *   `사 회\n(역사/도덕 포함)`, `기술∙가정/정보` 등 엑셀 내 특수 문자와 줄바꿈이 포함된 명칭을 정확히 매핑하도록 개선했습니다.
3.  **정밀한 학기별 합계**:
    *   사용자 규칙에 따라 `[n]` 형태의 텍스트를 제외하고 순수 학점 및 선택 블록 대표 학점만을 추출하여 계산합니다.

## 4. 최종 검토 의견 및 제언

*   **사회/과학 영역의 높은 선택권**: 강서고등학교는 사회(71학점)와 과학(55학점) 영역에서 매우 다양한 선택 과목을 제공하고 있어, 학생들의 진로에 따른 과목 선택 폭이 매우 넓음을 알 수 있습니다.
*   **기가정/정보 영역의 필수 확인**: 기술·가정/정보 교과군의 경우 모두 선택군에 배치되어 있으므로, 학생들이 졸업 전 최소 이수 기준을 충족할 수 있도록 안내가 필요합니다.
*   **학기별 균형 우수**: 모든 학기의 이수 학점이 31~33학점 사이로 유지되어, 학습 부담의 균형이 매우 잘 잡힌 교육과정으로 평가됩니다.

> **작성자 주**: 업데이트된 `verify_curriculum_v6.py`는 학교마다 상이한 선택 블록 구조를 자동으로 파악하여 지침 준수 여부를 검증합니다. 이 도구를 통해 향후 다른 학교의 교육과정도 동일한 정밀도로 분석 가능합니다.
