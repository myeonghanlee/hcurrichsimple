# 📚 고등학교 교육과정 편성 자율 점검 시스템 (v2.9)

본 시스템은 **GitHub**와 **Streamlit**을 활용하여 고등학교 교육과정 학점배당표를 자동으로 검증하고, 전문적인 분석 보고서를 생성하는 웹 애플리케이션입니다. 교육청의 지침과 자율 점검표 기준을 완벽하게 반영하여 업무 효율성을 극대화합니다.

---

## 🚀 핵심 기능 (Key Features)

### 1. 지능형 학교 유형 판별 및 대상별 분석

- **자동 분류**: 업로드된 파일을 분석하여 **일반 고등학교**와 **과학중점학교**를 자동 판별합니다.

- **과학중점 특화**: 과학중점학교의 경우 '일반 과정'과 '과학중점 과정'을 동시에 분석하며, 통합 시트 내의 '과중-지정' 필터링 및 가변 학점(`kk~ll`) 파싱을 지원합니다.

### 2. 고도화된 데이터 검증 엔진 (V2.9)

- **과목명 정밀 검증**: 과목명 끝의 공백이나 사이 띄어쓰기를 무시하고 100여 개의 고시 표준 명칭과 대조하여 오탈자를 찾아냅니다.

- **학점 정합성 체크**:
  - **학교 지정 과목**: 운영 학점과 학기별 배당 학점의 **합계**가 일치하는지 확인합니다.
  - **학년 선택 과목**: 배당 학점의 합계가 운영 학점의 **배수**인지 확인하여 편성의 적절성을 판별합니다.

- **지침 준수 판정**: 국·수·영 비중(50% 이내), 학기별 편차(5학점 이내), 필수 이수 학점 충족 여부 등을 자동 계산합니다.

### 3. 전문적인 결과 시각화 및 리포팅

- **통합 점검표**: 3개년도 데이터를 하나의 표에서 연도별로 비교할 수 있으며, 주의 항목은 **오렌지색**으로 강조됩니다.

- **교과군 상세 분석**: 국어, 수학, 영어 등 8개 주요 교과군별 최대 이수 가능 학점을 산출합니다.

- **디자인 적용 엑셀 다운로드**: 셀 병합, 배경색, 테두리, 열 너비 자동 조절(Auto-fit)이 적용된 전문 보고서 형태의 엑셀 파일을 생성합니다.

### 4. 사용자 편의 기능

- **3개년도 통합 관리**: 여러 파일을 한 번에 업로드하여 탭(Tab) 형식으로 관리합니다.

- **일괄 초기화**: 버튼 하나로 업로드된 파일과 분석 결과를 즉시 리셋할 수 있습니다.

## 📦 설치 및 실행 방법 (Local Setup)

1. **저장소 클론**:

   ```bash
   git clone https://github.com/your-username/curriculum-system.git
   cd curriculum-system
   ```

1. **환경 설정 및 패키지 설치**:

   ```bash
   pip install -r requirements.txt
   ```

1. **애플리케이션 실행**:

   ```bash
   streamlit run app.py
   ```

---

## 🌐 Streamlit Cloud 배포 가이드

1. **GitHub 업로드**: 본 프로젝트의 파일들(`app.py`, `requirements.txt`, `README.md` )을 GitHub 저장소에 업로드합니다.

1. **Streamlit 연결**: [Streamlit Cloud](https://streamlit.io/cloud)에서 해당 저장소를 연결합니다.

1. **배포 설정**: `Main file path`를 `app.py`로 설정한 후 배포합니다.

## 📂 파일 구조 (Project Structure)

- `app.py`: 시스템 메인 로직 및 UI 코드

- `requirements.txt`: 필수 라이브러리 목록 (`streamlit`, `pandas`, `openpyxl`, `xlsxwriter`)

- `README.md`: 시스템 안내 및 매뉴얼

## ⚠️ 유의 사항

- 엑셀 파일은 교육청에서 배포한 **표준 학점배당표 양식**을 기준으로 작성되어야 가장 정확한 분석이 가능합니다.

- 과목명 검증은 최신 고시 명칭을 기준으로 하며, 학교 자체 신설 과목이나 타시도 승인 과목은 '점검 필요'로 표시될 수 있으므로 검토자의 확인이 필요합니다.
